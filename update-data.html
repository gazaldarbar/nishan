UPDATE DATA

Turn a fresh IMDb ratings export into movies.json and series.json for The Watchlist. Runs entirely in your browser — nothing is uploaded anywhere.

1. Your new IMDb CSV

Export your full ratings from IMDb (Your Ratings → Export). It's cumulative, so this one file replaces the old data completely.

2. Corrections file (optional)

If you hand-corrected any titles in your repo before, upload your existing overrides.json here so those corrections survive this update. Skip this the first time — the tool will hand you a blank one to download instead.

Download movies.json Download series.json Download overrides.json (template)
Every month: get your new CSV from IMDb → run it through this page → replace movies.json and series.json in your GitHub repo (Add file → Upload files → same filenames → commit). That's it, no code involved.

Fixing a wrong category: instead of editing the big JSON files by hand, edit overrides.json — it's a short file. Add a line like "Some Movie Title": "Tamil" under "movies", or under "series" for series (using "Indian" or "Other"). Upload that same overrides.json back into step 2 next time you regenerate, and your fix will always be applied automatically, even after future CSV updates.
